Sreeved Prasad - Personal Portfolio

A modern, highly-interactive personal portfolio website built strictly with pure HTML and CSS - absolutely zero JavaScript is used.

Designed to showcase projects, skills, and certifications for an AI & Data Science B.Tech student, the site relies on advanced CSS techniques (like hidden radio buttons and sibling selectors) to seamlessly manage state, navigation menus, and modal pop-ups.

Features

 All interactivity, including the tab-based navigation, mobile hamburger menu, and certificate lightboxes, is powered solely by CSS.
Immersive Animations: Uses advanced CSS keyframes to create a dynamic background with floating aurora blobs, drifting particles, pulse rings, and geometric scanlines.
Responsive Layout: Fully adapts to desktop, tablet, and mobile screens using CSS Grid, Flexbox, and media queries.
Single-File Architecture: The entire website (HTML structure and CSS styling) is effortlessly self-contained within a single file.
Integrated Lightboxes: View your resume and certificates natively inside the browser via CSS-toggled hidden modals without ever leaving the page.
Sections Included

Home: Hero section with dynamic animations, typing effects, and quick links.
About Me: Brief background, current academic status, and core interests.
Projects: Custom-designed project cards with hover effects detailing major works (e.g., Vision-Guided Robotic Arm, Deep Learning Pipelines).
Skills: Categorized technical skills from Deep Learning to Structural FEA.
Certifications: Tappable animated cards revealing certificates in a full-screen CSS lightbox (DataCamp, SqlDBM, NVIDIA).
Education: Academic timeline and quick performance statistics.
Contact: Direct email/phone links, social profiles, and a functional HTML mailto communication form.
Tech Stack

HTML5: Semantic markup and state management via hidden radio and checkbox elements.
CSS3: Custom properties (CSS variables), complex sibling combinators, Flexbox layout, Grid systems, CSS transitions, and infinite keyframe transforms.
Usage & Setup

No build tools, frameworks, local servers, or dependencies are required.

Download the files to your local machine.
Open the .html file in any modern web browser (Chrome, Firefox, Edge, Safari).
Ensure the linked local media files (like resume.pdf, infra.jpg, certificate.pdf, etc.) are placed in the very same folder as the HTML file so the browser can display them correctly.
